A focused Chrome extension

Tabs in,
clean text out.

Distill Down turns the tabs you highlight into tidy Markdown, ready for your notes or AI tools. One click, on your device, with no account and no network requests.

Install from source ↗ Read the privacy policy
01

Converted locally

Pages are cleaned and converted in your browser. Distill Down makes no network requests.

02

Several tabs at once

Select the tabs you want, then make one combined document instead of copying page by page.

03

Markdown where you need it

Copy to the clipboard, save a Markdown file, or do both. You choose the destination.

Less clutter, more signal

Capture the part that matters.

Distill Down strips menus, footers and other page clutter from the main content. If you select at least eight words in the active tab, it captures just that selection.

Keep or remove links and image addresses, wrap clipboard text in a label for prompts, and control whether the source address keeps its query string and fragment.

How it works

A short path from reading to ready.

1

Select

Highlight the tabs you want to bring together.

2

Click

Click the Distill Down toolbar icon once.

3

Use

Paste the clean Markdown or open the saved file.

Ready when you are

Install from the repository.

Distill Down is not on the Chrome Web Store yet. Download the repository, load it as an unpacked extension, and start with the defaults—or open Settings to make them yours.
